# Jitjit turning frames

Original transparent artwork supplied by the user, ordered `1.png` through
`4.png` (front, right, back, left).

The app uses `assets/images/mascot_jitjit.gif`: 512 × 512 pixels, four frames,
240 milliseconds per frame, looping forever. Frames clear to transparent
between poses, with 255 artwork colors and one transparent palette entry.
`assets/images/mascot_jitjit.png` provides the front-facing static fallback
for reduced motion and inactive routes.

Jitjit appears on the Home Parents card, parent access screen, and Parent
Panel welcome card. Original frames remain outside the Flutter asset bundle.
